# v4 성능 개선 실험

**상태:** 첫 단계 145개 조건의 비교와 고정한 한 후보의 확인 평가를 완료했다.

**이번 결정:** 기존 활동량 보정 KNN을 유지한다. 확인용 주평가 10,000명에서 DAN의 Recall@10은 45.58%, 대조군은 40.51%였다. 전체 NDCG와 게임별 평균은 높아졌지만, 희귀 게임 NDCG는 이 표본에서 13.9% 낮았다.

확인용 희귀 구간은 322명·291개 게임이다. 적중 사용자 수는 대조군 22명, DAN 22명이다. 사전에 정한 점추정 비감소 규칙으로 교체 여부를 판정했다. 이 작은 표본의 차이를 실제 서비스 차이로 확정하지 않는다. 다른 후보로 확인 집단을 다시 시험하지 않았다.

새로 예약한 Kieran 계정에서 현재 모델을 재학습해 비교했다. 각 역할 20,000명 중 전체 입력 ≥5인 10,000명을 주평가로 삼고, 짧은 이력 10,000명은 별도 집단으로 보고한다. 세 역할은 결합 학습·설정 선택·확인용이며, 총 60,000명을 새 기초 학습에서 제외했다. 학습 자료는 긍정 77,881,718쌍이다. 기존 frank·Forgemaster 수치와 개선량을 직접 비교하지 않는다.

**독립성 한계:** 예약 계정은 과거 v1–v3의 학습에는 쓰였다. 현재 재학습의 학습·평가 계정 중복은 0이지만, 프로젝트 전체 개발 과정에서 완전히 미사용된 최종 테스트는 아니다. Forgemaster 계정과의 대조는 로컬 원자료 부재로 수행하지 않았다.

희귀 게임은 새 학습 자료에서 긍정 사용자가 1–999명인 정답이다. 전체 NDCG 차이의 짝지은 95% 신뢰구간 하한 >0, 전체 Recall·게임별 평균 NDCG·희귀 게임 NDCG 비감소, 빈 추천 비증가를 모두 요구한다. 기존 0 감소폭 기준을 결과를 본 뒤 완화하지 않았다.

주평가 10,000명은 정답 게임 1,133개를 포함하고, 그중 희귀 게임 정답은 342명·310개다. 게임 집합을 고정한 신뢰구간은 새로운 게임 모집단·재학습·설정 선택의 불확실성을 포함하지 않는다. 짧은 이력 집단도 정답을 숨긴 뒤 긍정 입력이 남는 사용자만 포함하므로 모든 신규 사용자를 대표하지 않는다.

게임 안 재표집에서는 사용자 한 명뿐인 게임의 변동을 추정할 수 없다. 주평가의 이런 게임은 520개, 희귀 구간에서는 310개 중 280개다. 게임별 신뢰구간은 이 한계를 가진 조건부 진단이며 모집단의 게임별 정확도를 보장하지 않는다.

## 후보 생성 진단

정답을 후보에 추가하지 않았다. 전체 Linux 후보 6,630개를 기준으로 평가하며, 후보 밖 정답과 빈 추천 사용자를 분모에 남겼다. 후보 포함률은 재정렬이 달성할 수 있는 상한이다.

## 검증과 해석

- 저장된 추천 목록에서 정답 순위를 재구성하고 후보·관측 게임 제외·점수·정렬·목록 길이를 검사했다. 완료한 감사는 각 평가 폴더의 `reporting_metrics.json`에 있다.
- 전체 차이의 신뢰구간은 같은 사용자를 짝지어 계산했다. 게임별 평균은 게임 집합을 고정하고 게임 안 사용자를 재표집했다. 이 구간은 재학습·여러 설정의 선택 불확실성을 포함하지 않는다.
- NDCG의 순위 로그와 평균은 float64로 계산한다. 초기 v4의 낮은 정밀도 집계는 예측 파일을 바꾸지 않고 수정했으며, 수정 전 영수증과 계산 코드를 보존했다. Recall과 적중 순위는 바뀌지 않았다.
- Recall@10은 숨긴 긍정 게임 하나를 추천 10개 안에서 회수한 비율이다. 사용자 만족도·전환율·추천 전체의 정밀도가 아니다.
- 고정 Qwen의 512/1,024 벡터는 동일하다. 원문 최대 길이가 소개글 220토큰·메타데이터 446토큰이어서 길이를 늘려도 추가 정보가 들어가지 않았다.
- 시간 노출 진단에서 기존 무작위 검증 입력의 57.60%가 정답보다 나중에 작성됐다. 이것은 노출 규모이며 성능 상승의 인과 효과가 아니다. 현재 결과를 미래 추천 성능으로 해석하지 않는다.

## 콘텐츠 관계 학습의 실패 진단

콘텐츠 정렬 계열에서 NDCG가 가장 높은 설정의 학습 그래프 20,000쌍을 점검했다. 교사 유사도의 중앙값은 0.004277이며, 98.50%가 미관측 쌍에 적용한 상한 0.05보다 작다. 따라서 이 상한만으로는 알려진 관계가 미관측 쌍보다 높은 점수를 갖게 만들지 못한다.

학습에 사용한 관계와 미관측 쌍을 점수로 구별하는 AUC도 0.5138로 거의 구분되지 않았다. 이 값은 학습 그래프 진단이며 예약 사용자의 추천 성능이나 독립 검증 점수가 아니다. 작은 회귀 오차만으로 정렬 학습이 성공했다고 볼 수 없으며, 콘텐츠 정렬 전체의 가능성을 기각한 결과로도 해석하지 않는다. 관계 사이의 상대 순위를 학습하는 손실과 학습 그래프 안의 별도 검증을 후속 실험으로 남긴다.

## 별도 시간순 대조 평가

주평가 820명에서 2022년 말 이전에 작성·수정된 리뷰로 다시 학습한 대조군을 평가했다. 현재 메타데이터를 사용한 상호작용 시간 통제 평가이며 무작위 숨김과 개선량을 직접 비교하지 않는다. 확인용 시간 구간은 열지 않았다. [결과와 추천 목록 검증](temporal_controls_v4.md)

## fSLIM 수치 검증

현재 학습의 공동 리뷰 행렬을 충분통계로 재사용했다. 같은 이웃 200/500개의 코사인 대조군과 비음수 L1+L2 회귀를 비교했다. 컴파일된 좌표 하강법의 작은 행렬 해를 독립 최적화와 대조했으며, 생산 학습의 정규화 KKT 잔차도 모두 사전 허용치 0.001보다 작았다. 최대 잔차는 0.000179였다. L1=0인 네 설정에서는 일부 게임 열이 1,000회 반복 상한에 도달해 dual-gap 정지 조건은 충족하지 못했다. 근사 최적성 검사를 통과한 계수의 결과이며, 모든 열이 정지 조건을 충족했다고 보고하지 않는다. 게임별 0 계수율·미수렴 열 수는 각 모델 manifest에 기록했다.

## 정답 시드 반복과 숨긴 부정 게임

주 모델을 고정한 뒤 확인 평가 전에 수행한 보고용 결과다. 첫 시드는 기존 20,000명의 정답·적중 순위·추천 목록을 정확히 재현했다. 세 시드의 결과를 사용자마다 평균한 뒤 신뢰구간을 계산했으며, 같은 사용자를 세 명으로 세지 않았다.

주평가의 시드 평균 Recall은 활동량 보정 KNN 40.21%, 고정 DAN 44.76%다. 보이는 부정 Linux 게임이 있는 2,395명에게 게임 하나를 추가로 숨긴 포함률은 각각 31.98%, 36.41%다. 이 보조 과제에서는 DAN이 싫어할 게임을 피하는 능력을 개선하지 못했다. 실제 추천에서는 이미 보이는 부정 게임을 계속 제외한다. 아직 리뷰하지 않은 모든 게임의 거짓 양성률로 해석하지 않는다.
