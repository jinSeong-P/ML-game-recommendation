# Kieran 학습·frank 평가의 초기 데이터 분석

분석 기준일: **2026-11-07**. 사용자는 **Kieran Steam Reviews v2 원본을 학습 원천으로, frank 리뷰를 테스트 원천으로 사용**하기로 확정했다. Kieran 원본 전체를 검증하고 frank의 모호한 리뷰–앱 연결을 평가 후보에서 제외해 규모를 계산했다. 재현 가능한 규칙으로 계정별 train/validation 분할도 미리 확인했다.

**후속 작업에서 최종 train/validation/test 파일을 생성하고 모든 분할 결과를 검증했다.** seed는 20261107이다. 실제 파일은 [분할 파일 안내](../docs/modeling_splits.md)에 정리했다. 2026-11-08에는 소개글·토큰·TF-IDF 인덱스·코사인 검색도 준비했다. [콘텐츠 준비 결과](../docs/tfidf_content.md)를 참고한다. 이 보고서 작성 시점에는 Item-KNN 학습과 두 모델의 공통 성능 평가가 아직 완료되지 않은 상태였다. Kieran–frank 기준선 평가는 이후 완료했으며 결과는 [baseline_v1.md](baseline_v1.md)에 있다. 최신 Forgemaster 모델 평가는 별도 데이터셋의 [forgemaster_model_evaluation.md](forgemaster_model_evaluation.md)에 기록했다. 원본 전체 자료를 대상으로 한 EDA 집계와 기대값은 이 보고서에 보존한다.

| 역할 | 고정한 범위 |
| --- | --- |
| 학습 원천 | Kieran original v2의 전체 `all_reviews.csv`; 계정 ID와 원 리뷰 ID는 문자열로 보존 |
| 평가 원천 | frank 고정 리뷰 자료에서 분석에 필요한 필드만 추출한 데이터. 완료된 후보 감사에서 확인한 모호 리뷰–앱 매핑은 평가 후보에서 제외 |
| 입력 앱 카탈로그 | A 자료에서 고정한 앱 목록을 평가 입력 범위로 사용. A의 익명 사용자 상호작용 행은 학습 이력으로 합치지 않음 |
| 정답 카탈로그 | 이전 A의 리뷰 존재·공식 Linux 지원 게임 6,630개. Kieran 리뷰 데이터에서 확인된 게임은 6,603개 |
| 고정 메타데이터 목록 | 이전 A/C에서 추출한 게임 목록과 설명·태그의 존재 여부. 실제 텍스트와 A/B/C 원본 비교는 legacy 자료에 보관 |

## 1. 데이터 경로와 원본 범위

현재 구성의 데이터 경로는 다음과 같다. 모든 경로는 저장소의 `EDA/` 기준이다.

| 용도 | 경로 |
| --- | --- |
| Kieran v2 원본 압축 파일 | `data/raw/kieran_original/` |
| Kieran 정규화 Parquet | `data/processed/kieran_original/` |
| frank 정규화 리뷰 필드 데이터 | `data/processed/frank/` |
| 고정 앱·Linux 카탈로그 및 A/C 메타데이터 스냅샷 | `data/reference/` |

Kieran v2 ZIP의 크기는 **17,241,297,932바이트**다. ZIP의 두 구성원은 전체 읽기로 CRC 검증을 통과했다. 학습 원천에는 42,487,005,552바이트의 `all_reviews/all_reviews.csv`만 사용했고, `weighted_score_above_08.csv`는 가중 점수로 추린 부분집합이므로 중복·표본 편향을 피하려고 정규화 원본에 섞지 않았다. 전체 CSV **113,883,717행**을 46개 Parquet 조각으로 기록했다.

| Kieran 전체 원본의 실측값 | 값 |
| --- | ---: |
| 원본 리뷰 행 | 113,883,717 |
| 정리 후 계정–앱 쌍 | 113,195,034 |
| 고유 Steam 계정 | 37,875,512 |
| 앱 수 | 105,838 |
| 긍정 리뷰 쌍 | 96,891,267 (85.60%) |
| 사용자별 리뷰 앱 수: p25 / 중앙값 / p90 / p99 | 1 / 1 / 6 / 25 |
| 앱 1개만 리뷰한 사용자 | 20,900,389 |
| 리뷰 작성 연도 | 2010–2023 |
| 최다 리뷰 상위 50개 앱의 리뷰 비중 | 32.31% (전체 정리 자료) |

리뷰는 계정이 Steam에서 작성한 평가 이력이지 전체 보유 라이브러리가 아니다. 원본 열 구조는 사용자·앱·원 리뷰 ID, 긍정 여부, 작성·수정 시각, 플레이 시간, 언어를 포함한다. 이번 정규화에는 리뷰 본문을 넣지 않았다. frank 지정한 Git 커밋의 리뷰 행 2,631,430개에서 분석에 필요한 필드를 추출했다. 라벨 충돌 정리·쌍 통합 후 2,631,416쌍·1,336,109계정·44,517개 앱이다. 이는 알려진 모호 리뷰를 평가 범위에서 제외하기 전의 전체 원천 규모다. 입력 앱이 없다는 이유만으로 부정 선호로 간주할 수 없으며, 부정 라벨은 실제 부정 리뷰가 관측된 경우에만 사용해야 한다.

## 2. 데이터 품질과 정리

사용자 ID·앱 ID·원 리뷰 ID·라벨의 형식 오류나 결측은 원본에서 각각 **0건**이었다. 사용자 ID와 원 리뷰 ID를 처음부터 문자열로 읽어 큰 Steam ID가 부동소수점 변환으로 바뀌지 않도록 했다. 여기서 원본 파싱 무효 행이 0이라는 뜻은 앱 연결이나 라벨 충돌도 0이라는 뜻이 아니다.

| 점검·정리 항목 | 발견값 | 처리·해석 |
| --- | ---: | --- |
| 동일 원 리뷰 ID의 앱 연결 충돌 | 332,865개 ID / 686,161행 | 앱 연결이 불명확한 원 리뷰 ID 전체를 학습·평가 자료에서 제외 |
| 동일 원 리뷰 ID의 내부 작성자 충돌 | 0개 | 내부 계정 매핑 충돌은 관측되지 않음 |
| 같은 라벨의 반복 행 | 2,375행 | 중복 제거 |
| 긍정/부정 라벨 충돌 | 72개 계정–앱 쌍 (167행) | 충돌 쌍은 사용하지 않음 |
| 수정 시각이 작성 시각보다 이른 행 | 2행 | 시간 열의 예외로 기록 |
| 플레이 시간 결측 / 음수 | 8행 / 0행 | 결측은 일부 행에만 존재, 음수 없음 |
| 플레이 시간 0인 행 | 1,735,970행 | 0은 유효 관측값으로 유지 |

정리 후에도 여러 언어가 포함된다. 원본 상위 언어는 영어 51,544,612행, 중국어 간체 17,589,884행, 러시아어 12,896,431행이며 한국어는 2,281,000행이다. 영어만 남기는 필터는 적용하지 않았다. 플레이 시간은 리뷰 작성자 쪽 스냅샷 값이며 보유 여부의 대체 지표로 취급하지 않는다.

## 3. 정확한 Steam 계정과 원 리뷰 교차 검증

Kieran 계정 ID는 정확한 문자열을 기준으로 비교했다. frank와 공통인 원 리뷰 ID **1,089,913개**에서 작성자 불일치는 **0개**였다. 정리 전에는 그중 **185개**의 앱 연결이 달랐고, 이 연결 충돌은 정리 후 공유되는 원 리뷰 ID에서 남지 않았다. 두 출처 사이에 라벨이 달라진 공통 원 리뷰 ID는 **12,600개**이며, 정리된 공통 계정–앱 쌍 기준으로는 **12,574개**다. 학습 라벨은 Kieran 정리본을 따르고 frank의 라벨을 학습에 섞지 않는다.

이 검증은 정확한 계정 단위 제외를 뒷받침한다. 숫자 ID를 부동소수점으로 읽거나 반올림한 식별자로 분할하지 않는다. Kieran 및 교차 출처 대조에서 모호한 원 리뷰–앱 연결과 계정–앱 라벨 충돌을 제외한 뒤에는 학습 후보와 고정 평가 계정 사이의 사용자, 사용자–앱, 원 리뷰 ID 교집합이 각각 **0**임을 확인했다. 이 검사는 사용자 누수와 리뷰 중복을 점검하지만, 라벨의 대표성이나 시간적 미래 예측 성능을 보증하지 않는다.

## 4. 계정 단위 분할과 학습 규모 미리보기

frank 쪽의 고정 평가 계정 명단은 **87,573개 Steam 계정**이다. 이 수는 학습 제외를 위한 보수적인 상위 집합이며, Kieran 원본에 실제로 존재해 제거한 계정 수와 같지 않다. Kieran에 매칭된 **79,879개 계정**의 모든 앱 리뷰 **3,360,025쌍**을 제외했다. 그 결과는 다음과 같다.

| 단계 | 계정 수 | 계정–앱 쌍 | 긍정 쌍 |
| --- | ---: | ---: | ---: |
| Kieran 정리본 전체 | 37,875,512 | 113,195,034 | 96,891,267 |
| frank 평가 계정과 겹치는 계정 전체 제외 후 | 37,795,633 | 109,835,009 | 94,206,307 |
| 검증 계정 예약 후 train 미리보기 | 34,014,115 | 98,857,701 | 84,791,317 |
| 별도 validation 예약 미리보기 | 3,781,518 | 10,977,308 | 9,414,990 |

검증 집합은 평가 계정을 제외한 나머지 계정 중 `MD5("steam-eda-validation-v1:<정확한 Steam ID>")`의 첫 15개 16진수 숫자를 정수로 해석해 10으로 나눈 나머지가 0인 전체 계정으로 예약한다. 같은 해시 이름 공간을 모든 출처에 사용한다. 계정을 행 단위로 나누지 않으므로 한 계정의 다른 앱 리뷰가 train과 validation/test에 나뉘지 않는다.

**당시 98,857,701쌍은 train 미리보기였고, 이후 생성한 전체 train 분할에서도 같은 행 수를 확인했다.** 실제 Item-KNN 입력은 고정 카탈로그 긍정 78,315,268쌍이다. 기존 EDA JSON은 당시 집계로 보존하고, 최종 파일·검사 결과는 [분할 결과](modeling_split_v1.json)에 별도로 기록했다. 모델 선택은 예약된 validation에서 수행하고, test 계정은 최종 보고용 평가에 남겨 둔다.

## 5. 정리된 frank 평가 후보와 프로토콜

이전 후보 감사의 두 원본에서 확인한 모호 리뷰–앱 매핑 합집합을 고정 목록으로 보존하고 frank 평가 후보에서 제외했다. artermiloff의 손상된 작성자 ID 차이만으로 frank 리뷰를 제거하지 않았다. frank에서 영향을 받는 원 리뷰 ID는 **296개**다. 기존 평가 계정 이력에서는 **77개 계정–앱 쌍 / 77명**이 영향을 받고, 그중 잠재 Linux 긍정 정답 후보는 **38쌍**이다.

평가는 고정 A 리뷰 앱 카탈로그에서 입력을 만들고, A의 공식 Linux 카탈로그에 속한 frank의 긍정 리뷰 하나를 정답 후보로 숨기는 설계다. 한 사용자의 잠재 목표 게임이 여럿일 수 있으므로 사용자 수와 가능한 사용자–정답 쌍 수는 구분한다.

| 숨긴 긍정 정답 외에 남아야 할 최소 리뷰 입력 수 | 잠재 사용자 | 남은 입력에 긍정 리뷰가 있는 사용자 | 부정 입력만 남는 사용자 | 가능한 사용자–정답 쌍 |
| ---: | ---: | ---: | ---: | ---: |
| 1 | 87,557 | 78,228 | 9,329 | 184,082 |
| 3 | 39,450 | 38,549 | 901 | 125,593 |
| **5** | **24,571** | **24,342** | **229** | **102,602** |
| 10 | 11,647 | 11,609 | 38 | 76,056 |

이 표는 모델링 규칙을 확정하기 전에 집계한 평가 후보 규모다. **24,571명은 숨김 후 전체 입력 ≥5 조건만 적용한 중간점검 집단**이며, 사용자별 정답 후보가 여러 개라 가능한 사용자–정답 쌍은 102,602개다. 확정한 기본 평가는 숨김 후 전체 입력 ≥5와 긍정 입력 ≥1을 모두 요구하며, 예상 인원은 **24,342명**이다. 24,571명에서 남은 입력이 모두 부정인 229명을 뺀 수다.

이 집계는 실제 사용자별 정답 명단을 만들기 전의 예상 규모였다. 이후 같은 24,342명을 실제 테스트 사용자로 고정했다. 입력 461,599쌍과 정답 24,342쌍을 저장하고 검증했다. 평가할 때는 각 적격 사용자에게서 정답 하나를 균등 무작위로 골라 seed와 명단을 저장한다. 정답 여러 개를 동시에 숨기는 평가는 별도 작업이다.

입력 수에는 긍정·부정 리뷰 게임을 모두 포함한다. 확정한 기본 평가 집단 24,342명은 숨긴 정답 외에도 긍정 입력이 하나 이상 남는다. 전체 입력 ≥5만 적용한 중간점검 집단의 나머지 229명은 입력이 모두 부정이어서 긍정 전용 기본 프로필을 만들 수 없으므로 기본 평가에서 제외했다. 두 모델은 취향과 점수를 계산할 때 긍정 리뷰만 사용한다. 남은 긍정·부정 입력 게임은 추천 후보에서 제외하고 숨긴 정답은 후보로 둔다. 리뷰가 관측되지 않은 게임을 부정 라벨로 처리하지 않는다.

24,342명은 87,573명보다 작은 **정제된 평가 후보 집단**이다. 이전 진단에서 전체 입력 ≥5만 적용한 집단은 24,571명이므로 두 수를 구분해 인용한다. 이 24,571명 집단에서 모든 평가 입력·정답 게임에 Kieran train 리뷰가 적어도 하나 있어야 한다는 조건을 더하면 **24,479명**이다. 각 게임에 Kieran train 긍정 사용자가 최소 5명 있어야 한다는 더 엄격한 조건에서는 **24,339명**이다. 이 과거 진단 결과는 원래 평가 후보 수를 대체하지 않으며, 선택한 모델의 최종 test 명단 크기나 실제 추천 가능 범위를 뜻하지 않는다.

## 6. 카탈로그와 메타데이터 범위

고정 Linux 정답 카탈로그는 총 **6,630개 앱**이고, 전체 Kieran 리뷰에서 확인되는 Linux 앱은 **6,603개**다. 6,630은 타깃 카탈로그 크기, 6,603은 리뷰 원천에서 관측된 앱 수이므로 서로 다른 값이다. 고정 입력 카탈로그 자체는 37,610개 앱이며, 그중 전체 Kieran 정리 리뷰에 존재하는 앱은 37,363개다. 이 목록은 평가할 앱 범위를 정하는 기준이다. A의 익명 사용자 이력을 frank 입력이나 Kieran 학습 자료에 붙이지 않는다.

| A/C 메타데이터 연결 점검 | 앱 수 또는 쌍 수 |
| --- | ---: |
| Kieran 원본 앱 중 A 메타데이터 있음 | 49,807 |
| Kieran 원본 앱 중 C 메타데이터 있음 | 62,961 |
| C에만 메타데이터 있음 | 27,164 |
| A와 C 모두 연결되지 않음 | 28,867 |
| 비어 있지 않은 설명 / 태그가 확인된 앱 | 67,785 / 72,205 |
| train 규모 미리보기에서 설명 없음 | 5,538,704쌍 |
| train 규모 미리보기에서 태그 없음 | 5,492,151쌍 |
| train 규모 미리보기에서 A/C 메타데이터 자체가 없음 | 1,390,023쌍 |

설명·태그가 비어 있지 않은지는 데이터 존재 여부만 확인한 결과다. 텍스트의 품질이나 정확성을 인증하지는 않는다. 고정 메타데이터 목록에는 앱 식별자, Linux 표식, 메타데이터 존재 여부만 남겼고 설명·태그 원문은 포함하지 않았다. TF-IDF 입력 자료는 이후 별도로 준비했다. A의 익명 상호작용과 C의 평판·인기도 집계는 학습 리뷰로 쓰지 않는다. 제품 종류·지역판·번들·에디션을 완전히 통합했거나 메타데이터 시점이 일치한다고 보장하지 않는다. 입력·정답 게임 목록을 고정했으므로 신규 앱에 대한 일반화 실험도 아니다.

## 7. 평가 해석과 남은 작업

2026-11-07에 베이스라인 설계를 확정했다. Item-KNN은 비Linux 게임을 포함한 고정 입력 목록 **37,610개 게임**에서 학습한다. 긍정 리뷰가 한 게임뿐인 사용자도 아이템 빈도와 코사인 정규화에 포함한다. 이 목록 안의 긍정 쌍은 EDA 미리보기 기준 **78,315,268개**다. App ID 연결을 확정할 수 없는 원 리뷰는 계속 학습에서 제외한다.

TF-IDF는 게임 소개글만 사용한다. A `description`을 우선하고, 값이 null·빈 문자열·공백뿐일 때 C `short_description`으로 보충한다. 태그·장르는 베이스라인 특징에 포함하지 않는다.

기본 평가는 사용자마다 적격 긍정 Linux 정답 하나를 균등 무작위로 숨긴다. 숨김 후 전체 입력이 5개 이상이고 긍정 입력이 1개 이상인 **24,342명**이 EDA 잠재 평가 규모다. 두 모델은 긍정 입력만 취향·점수에 사용하고 동일 가중 평균으로 집계한다. TF-IDF는 L2 정규화한 긍정 게임 벡터 평균과 후보의 코사인 점수, Item-KNN은 후보와 각 긍정 입력의 유사도 합을 긍정 입력 수로 나눈 점수를 쓴다. 남은 긍정·부정 리뷰 게임은 후보에서 빼고 숨긴 정답은 추천 가능하게 둔다. 개인화 점수가 0보다 큰 게임만 최대 10개 추천하며, 양수 점수 후보가 10개보다 적으면 추천 목록의 나머지 자리는 채우지 않는다. 빈 추천 목록을 받은 적격 사용자도 Recall@10·NDCG@10 분모에 유지한다.

이번에 추가한 실험은 **전체 입력 ≥3·긍정 입력 ≥1 평가**, **플레이타임 가중 대체 집계 비교**, **모델 개선 후 train 데이터의 인기도 순으로 추천 목록의 남은 자리를 보완하는 실험**이다. 복수 정답 숨김, 태그·장르 보강, 부정 신호 실험도 추가 작업으로 남아 있다. 추가 실험 목록에 넣었다는 뜻이며 당시 구현을 끝냈다는 뜻은 아니다.

실제 train/validation/test 분할과 정답 목록·검증 정보는 생성·검증을 마쳤다. TF-IDF 카탈로그의 어휘·IDF·벡터와 검색도 준비했다. 이 보고서 작성 당시에는 Item-KNN 학습과 두 모델의 공통 성능 평가가 아직 완료되지 않은 상태였다. 이후 완료한 기준선 결과는 [baseline_v1.md](baseline_v1.md)에 기록했다. 전체 게임 기준 긍정 84,791,317쌍과 고정 입력 카탈로그 기준 78,315,268쌍은 서로 다른 EDA 범위의 수치다. 세부 규칙은 [모델링 결정과 추가 실험 목록](../docs/modeling_backlog.md), 평가 방식 비교는 [정답 숨김 방법 비교](../docs/holdout_options.md)에 기록했다.

2026-11-07 [중간점검 의심점 판정](kieran_frank_midpoint_audit.md)에서 분포 차이, 불완전한 긍정 이력, 모호한 앱 연결을 제외하면서 생긴 손실, 학습 긍정 사용자 수가 적은 게임, 메타데이터 불일치를 확인했다. 사용자별 제외 마스크를 적용했을 때 인기도 Recall@10의 기대값은 frank의 과거 전체 입력 ≥5 진단 집단에서 0.05814%, Kieran 내부 검증의 같은 입력 조건에서 31.96755%다. 특정 seed로 측정한 최종 모델 성능이 아니라 정답 하나를 고를 때의 기대값이다. Item-KNN과 TF-IDF의 우열을 나타내지 않는다. 원본 전체 자료를 대상으로 한 집계는 보존하고 평가 해석과 모델 입력 범위를 보완한다.

- frank는 앱당 최대 100개 리뷰를 담은 리뷰 자료이므로 긴 보유 목록이나 전체 라이브러리 기반 평가가 아니다. 숨긴 리뷰 시각에 맞춰 모든 입력의 시점을 제한하지 않았으므로 미래 리뷰 예측 평가로 해석하지 않는다.
- Kieran 원본은 2010–2023년 다국어 리뷰다. 항목별 리뷰 수가 크게 치우치며 상위 50개 앱이 전체 정리 리뷰의 32.31%다. 후보 아이템에 대한 train 긍정 근거가 없는 경우도 있다. 넓은 사전 진단에서는 정리 전 후보 184,125쌍을 살폈다. 검증 계정을 학습에서 제외한 뒤 train 긍정 리뷰가 없는 정답 후보는 447개였다. 이 학습 근거 진단은 기본 평가 후보 24,342명과 과거 전체 입력 ≥5 진단 집단 24,571명을 구분해 기록해야 한다.
- 2026-11-07 분석 시점에는 인기도 기준선, 협업 필터링, k-core, 이웃 그래프와 임베딩을 학습하거나 만들지 않았다. 계정 분리된 실제 모델 입력 행과 재현 가능한 정답 명단은 저장·검증했다. 이 시점에는 학습 행렬·추천·지표 산출 코드도 아직 구현 전이었다. 이후 완료한 Kieran–frank 기준선 학습·평가 결과는 [baseline_v1.md](baseline_v1.md)에 있다.
- **완료된 분할 산출물:** 전체 train 98,857,701쌍, Item-KNN 입력 78,315,268쌍, 전체 validation 10,977,308쌍, 검증 평가 325,639명, frank 평가 24,342명 및 실제 query/target·사용자 명단·원 리뷰 계보. 24,571명은 과거 전체 입력 ≥5 진단 집단이다. **완료된 콘텐츠 산출물:** 소개글·토큰·TF-IDF 희소행렬·어휘/IDF·코사인 검색. **이 보고서 작성 당시 미완료였던 산출물:** Item-KNN 학습 행렬·이웃, 고정 평가 집단 전체 추천·성능 결과표. 이들 후속 결과는 [baseline_v1.md](baseline_v1.md)에 기록했다.
