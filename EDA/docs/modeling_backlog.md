[v1 결과](../reports/baseline_v1.md), [v2 실행 결과](../reports/model_improvement_v2.md)와 [모델 실행 안내](baseline_models.md)를 기준으로 완료 상태를 구분한다.

**분할 생성 완료:** `split_v1`, seed **20261107**로 전체 train/validation, Item-KNN 긍정 학습 입력, 검증·frank query/target·사용자 명단·제외 목록을 저장하고 전수 검증했다. 학습 긍정은 **78,315,268쌍**, 검증 평가는 **325,639명**, 테스트는 **24,342명**이다. 실제 경로와 검증 근거는 [분할 파일 안내](modeling_splits.md)에 기록했다. 2026-11-08 소개글·토큰·TF-IDF 인덱스·코사인 검색도 준비했다. [콘텐츠 준비 결과](tfidf_content.md)에 지원 범위와 한계를 기록했다. Item-KNN(K=100) 학습과 고정 사용자 전체 공통 검증·frank 테스트도 완료했다.

## 모델 개선 실행 — v2 완료

2026-11-08 사용자가 승인한 네 단계 실행을 완료했다. [실행 절차와 시각화](model_improvement_execution.md)에 목적·작업·완료 조건을, [v2 프로토콜](../data/reference/improvement_protocol_v2.json)에 실험값·보호 지표·채택 기준을 고정했다. 기존 v1 규칙·결과는 보존하고, 최종 검증 선택은 [선정 스냅샷](../data/reference/improvement_selection_v2.json)에 동결했다. Item-KNN은 보호 기준에 따라 v1을 유지하고 콘텐츠는 T2+메타데이터 50:50을 선택했다. 고정 모델의 frank 참조 평가도 완료했으며 자동 테스트 85개가 통과했다.

**재현 단계 확인:** [재현 스크립트](../scripts/reproduce_improvement_review.py)와 [집계](../reports/baseline_review_reproduction_v2.json)에 v1 성능·지문·인기도 기준선·저장 연결의 공동 리뷰 수·결측·추천 쏠림·기존 frank의 사후 코사인 민감도를 기록했다. 다음은 기존 중간 검토 기록의 해석 보완이며, 원래 기록과 구분한다.

- 46.1%는 Linux 후보 토큰 수 80분위 경계 **45토큰 초과** 게임의 추천 자리 비중이다. 경계 동점 때문에 이 게임은 정확한 상위 20%가 아니라 1,252/6,630개(18.88%)다. App ID 동점 규칙으로 정확히 20%인 1,326개를 고르면 47.12%다.
- 불용어 21개 목록·분모가 남지 않아 해당 가중치 비중은 원래 정의대로 재현하지 못했다. T0의 명시한 단어 목록/DF와 실제 점수 기여를 새 근거로 사용한다.
- 소개글 결측 5.81%는 **동일한 고정 소개글만 쓰는 T1~T3**의 지원 한계다. 태그·장르를 보강하는 T4나 새 정보원을 포함한 모든 TF-IDF 설정의 불가능을 뜻하지 않는다.
- 인기도 구간 재가중은 기술적 근사치이며 인과 설명이 아니다. 검증의 지원 0 정답 부재도 가정으로 명시한다. 검증 가중치·사용자 명단을 frank에 맞추지 않는다.
- 추천 게임의 train 지원 수와 입력–후보 연결의 공동 사용자 수는 다른 통계다. 희귀 게임 추천 중앙값만으로 약한 연결의 유해성을 확정하지 않는다.
- 두 Top10 적중의 합집합 12.25%는 실제 결합 모델 성적이 아니다. 0.91%는 **Item-KNN 정답 점수가 0인 사용자**의 조건부 TF-IDF 적중률이며, 추천 목록 전체가 빈 사용자만의 성적이 아니다. 코사인 조건으로 사용자를 뺀 수치도 사후 진단이고 공식 지표·튜닝 기준으로 사용하지 않는다.

2026-11-08 [Item-KNN·TF-IDF 개선 기획안](model_improvement_plan.md)을 실행했다. 기존 v1의 확정 규칙과 완료 결과를 유지하고 아래 v2 진단·검증을 별도 버전으로 수행했다. 실제 성능·보호 조건과 최종 선택은 [v2 실행 결과](../reports/model_improvement_v2.md)에 기록한다.

- [x] **완료 — Item-KNN 연결 실패 분해(K0):** train 지원 0·긍정 입력 지원 0·원시 연결 없음·절단·순위 실패·적중의 전수 여섯 범주를 저장했다. 검증 325,639명·frank 24,342명 합계와 v1 0점·적중을 재현했다. frank는 관측 참고다.
- [x] **완료 — Item-KNN 이웃 수·감쇠(K1/K2):** K=100/200/500 × λ=0/10/50의 사전 지정 9개 조합을 내부 검증했다. 감쇠 후 모든 원시 연결에서 이웃을 다시 고르고 K100/λ0의 v1 완전 일치를 확인했다. 전체 평균이 좋아진 후보도 게임별 평균·지원 1–999 보호 기준을 통과하지 못해 v1을 유지한다.
- [x] **완료 — TF-IDF 진단·단독 변경(T0~T3):** 341개 층화 사례·7,243개 단어 기여를 저장하고 sublinear TF, unigram+bigram, 조건부 max_df=0.5를 각각 비교했다. 고빈도 단어의 오추천 기여 19.31%로 T3 실행 조건을 충족했다. 소개글 단독 최선은 T2이며 T4 전에 고정했다.

태그·장르 보강(T4), 다국어 분절과 입력 집계는 아래 기존 백로그와 연결한다. 기존 frank는 이미 관측된 참조 테스트로 구분하고, 후속 설정 선택은 train/validation에서만 수행한다.

## 구현 백로그

- [x] **완료 — 소개글 TF-IDF 입력과 검색:** A `description` 우선·C `short_description` 결측 보충 원문·정리 텍스트·토큰·출처를 저장했다. 기본 단어 TF-IDF와 L2 정규화 벡터, 긍정 입력 동일 가중 평균·Linux 코사인 검색을 구현·검증했다. CSR 행렬과 ID 매핑을 사용하며 전용 벡터DB는 도입하지 않았다. 유효 벡터는 전체 37,527개·Linux 6,613개다. 자동 언어 판별·CJK 분절·성능 튜닝은 적용하지 않았으며 공통 검증·frank 테스트는 동일한 소개글 설정으로 완료했다.
- [x] **완료 — 긍정 신호 베이스라인:** Item-KNN은 Kieran 학습 계정의 공동 긍정 리뷰로 이웃을 학습하고, 두 모델은 평가 사용자의 남은 긍정 리뷰만 취향·순위 점수에 사용한다. 남은 입력 이력의 긍정·부정 게임 모두 후보 마스크에 반영한다. 정답으로 숨긴 게임은 이 마스크에서 제외해 추천 가능하게 한다.
- [x] **완료 — 분할 파일·무작위 정답 1개 고정:** seed **20261107**, 숨김 후 전체 ≥5·긍정 ≥1 조건으로 실제 train/validation, 긍정 학습 입력, 검증·테스트 query/target·제외 목록·사용자 명단·원 리뷰 계보를 저장했다. 저장 파일의 83개 위반 검사와 소스 대조 감사 11개 모두 0이며, 전체 예약 87,573명을 학습·검증에서 제외했다. [생성·검증 결과](modeling_splits.md) 참고.
- [x] **완료 — 고정 분할에서 기본 평가:** 두 모델이 생성된 동일 사용자·입력·정답·후보를 읽도록 구현한다. 양수 개인화 점수로 최대 10개 추천하고 부족한 자리는 비운다. 빈 목록도 평가에 남기며 정답을 못 찾으면 Recall@10·NDCG@10은 0이다. 동일 분할 전체에 대한 추천·지표 저장과 재검사를 완료했다. 테스트 Recall@10은 TF-IDF 3.5782%, Item-KNN 11.1905%이며 [결과 보고서](../reports/baseline_v1.md)에 진단을 함께 기록했다.

## 중간점검 의심 사항의 검증 결과

2026-11-07 로컬 자료를 읽기 전용으로 재집계하고 사용자별 후보 제외를 반영한 무작위·인기도 기준선의 기대값을 계산했다. 상세 근거와 제한은 [중간점검 판정 보고서](../reports/kieran_frank_midpoint_audit.md)에 기록했다. 아래 완료 표시는 **의심점 검증 완료**이며, 개선 조치·모델 학습·최종 분할 완료나 미결정 규칙의 사용자 승인을 뜻하지 않는다. [기존 진단 관측값](../reports/kieran_frank_eval_diagnostics.json)도 이력으로 보존한다.

- [x] **frank 정답 분포 차이 — 확인:** 사용자별 제외 마스크를 적용한 인기도 Recall@10 기대값은 0.05814%, 무작위는 0.15093%다(전체 입력 ≥5, 24,571명). 인기도가 무작위보다 낮다는 의심은 확인됐다. 이는 최종 seed 전의 기대값이다. 이후 고정 명단에서 측정한 Item-KNN·TF-IDF 성능과 실제 인기도 기준선은 [베이스라인 보고서](../reports/baseline_v1.md)에 별도 기록했다.
- [x] **검증·테스트 분포 차이 — 확인:** 같은 전체 입력 조건의 Kieran 검증 인기도 Recall@10 기대값은 31.96755%로 frank와 크게 다르다. 검증에서 고른 모델 설정이 실패한다고 입증된 것은 아니다. 모델 설정은 계속 내부 검증에서만 고른다.

## 베이스라인 v1 중간 검토 후속 작업

아래 항목은 2026-11-08 v1 읽기 전용 중간 검토에서 시작했다. 당시 지표 재계산·사용자 2,000명 추천 재계산·누수·지문 검사와 자동 테스트 53개에 불일치가 없어 [v1 결과](../reports/baseline_v1.md)를 유지했다. 이후 [재현 스크립트](../scripts/reproduce_improvement_review.py), K0/T0 산출물, v2 실험으로 확인한 부분은 완료 표시하고 미해결 원인과 후속 작업은 남겼다.

실험 후보와 순서는 [개선 기획안](model_improvement_plan.md)의 K·T 항목을 따른다. 여기에는 그 기획을 실행하기 전에 정할 사항과 근거 수치만 적는다.

## 부정 리뷰 베이스라인과 후속 실험

첫 방법을 베이스라인으로 선택했고 나머지는 후속 실험이다. 부정 리뷰를 입력 데이터에 보존하는 것과 학습·추천 점수에 실제 사용하는 것을 구분한다. 이미 남은 입력에서 리뷰한 게임은 긍정·부정 모두 재추천 후보에서 제외한다. 숨긴 정답은 입력 이력·취향·후보 제외 마스크에서 모두 제거한다. 아직 리뷰하지 않은 게임을 부정 라벨로 취급하지 않는다.

| 방법 | 적용 위치 | 동작 | 장점·한계 |
|---|---|---|---|
| **확정 베이스라인 — 긍정 신호만으로 순위 계산** | 사용자 입력 집계 | 긍정 리뷰 게임만 취향 벡터·추천 점수에 사용. 부정 리뷰한 게임 자체는 재추천에서 제외 | 단순한 비교 기준. 비슷한 다른 게임에 대한 부정 신호는 전달되지 않음 |
| 후속 — 부정 게임 유사도 감점 | 사용자 입력 집계·후보 점수 | 긍정 게임과의 평균 유사도에서 부정 게임과의 평균 유사도 × 감점 계수를 뺌 | 기존 TF-IDF와 양의 Item-KNN 유사도를 유지하며 적용 가능. 가격·버그 때문에 싫어한 게임을 취향 불일치로 확대할 수 있음 |
| 후속 — 부정 게임의 유사 후보 제외 | 후보 필터 | 부정 리뷰 게임과 유사도가 일정 값 이상인 새 후보를 제외 | 명확한 회피 규칙. 임계값에 따라 추천 후보를 과도하게 잃을 수 있음 |
| 후속 — 학습에 긍정·부정 관계 반영 | Item-KNN 유사도 학습 | Kieran 학습 리뷰의 긍정–긍정과 긍정–부정 관계 등을 구분해 이웃·추천 점수를 구성 | 집단의 부정 선호 패턴 활용 가능. 단순 +1/−1 코사인은 공동 부정도 양의 유사도에 기여하므로 관계별 의미·관측 여부·지원 수를 별도로 설계해야 함 |

TF-IDF에서 긍정 소개글 벡터 평균에서 부정 소개글 벡터 평균을 빼는 Rocchio형 프로필도 가능하다. 입력 게임 벡터와 후보 벡터가 같은 방식으로 L2 정규화되어 있고 같은 가중치를 사용한다면, 위 평균 유사도 감점과 후보 순위가 같아질 수 있다. 최종 사용자 벡터의 L2 정규화만 추가하는 것은 독립된 순위 개선 실험이 아니다.

부정 입력이 없으면 후속 감점은 0이다. 현재 기본 평가는 숨김 후 긍정 입력 ≥1을 요구해 긍정 입력 없는 사용자를 공통 제외한다. 적격 사용자라도 모델이 양수 점수를 만들지 못하면 빈 목록을 반환하고 평가에는 남긴다. 감점 계수·필터 임계값은 후속 실험에서 검증셋으로 정하며 테스트셋으로 조정하지 않는다.
