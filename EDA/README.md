# Steam 게임 추천 데이터 탐색 결과

이 문서는 리눅스 지원 Steam 게임 추천 프로젝트의 데이터 탐색(EDA) 결과와 해석을 정리한다. 분석 대상은 실행 결과가 저장된 `Steam_EDA_Colab (1).ipynb`이며, 추천 모델 학습이나 성능 평가 결과는 아니다.

## 먼저 확인할 점

**A 리뷰의 수치와 그래프는 Colab이 읽은 파일 기준이다.** Colab의 `recommendations.csv` 크기는 약 **824.2 MB**였고, 이 작업 공간에서 확인한 파일은 약 **2,023.2 MB**였다. 노트북 설정이 `FULL_DATA = True`여도 Colab에 있는 파일을 대상으로 실행한다는 뜻이며, 로컬 전체 원본을 읽었다는 증거는 아니다.

이번 A 분석에는 1,681만여 행과 2,827개 게임이 포함됐다. Colab 파일이 어떻게 만들어졌는지와 원본에서 어떤 행이 선택됐는지는 확인되지 않았다. 따라서 **무작위·대표 표본이라고 가정할 수 없고**, A의 비율·사용자별 이력·인기 순위는 전체 데이터의 확정치가 아니다.

A 리뷰 읽기에는 `ignore_errors=true`가 설정돼 있다. 이 옵션은 CSV 읽기 오류가 있는 행을 건너뛸 수 있으며, 이번 실행에서 건너뛴 행의 수는 기록되지 않았다. `missing_user = 0` 같은 결과도 **읽힌 행 안에서의 결과**다. B는 이번 실행에서 기본 pandas 파서로 읽혔으며, B의 예외 처리에도 오류 행을 건너뛸 수 있는 코드가 있다.

## 기획안과 데이터의 역할

| 구분 | 파일 | 이후 프로젝트에서의 용도 |
|---|---|---|
| A | `recommendations.csv` | 사용자–게임 리뷰, 추천 여부, 날짜, 플레이 시간. 아이템 기반 협업 필터링의 학습 자료 후보 |
| A | `games.csv` | 게임 제목, Steam App ID, 운영체제 지원 정보. 이 EDA에서는 공식 Linux 지원 게임을 구분하는 기준 |
| A | `games_metadata.json` | 게임 설명·태그 등 콘텐츠 기반 추천의 입력 후보 |
| B | `games_march2025_cleaned.csv` | 설명·장르·태그 등 게임 콘텐츠 보강. A와 게임 ID로 연결 |
| C | `australian_user_reviews.json` | 외부 사용자의 긍정 리뷰로 취향 입력과 숨긴 평가 정답을 구성하는 데 사용할 후보 |

기획안의 두 기본 추천 방법은 **TF-IDF와 코사인 유사도를 이용한 콘텐츠 기반 추천**, **아이템 기반 KNN 협업 필터링**이다. 두 방법에 Linux 지원 조건을 적용하고 Top 10을 비교한다. Recall@10, NDCG@10, Diversity, Coverage는 향후 모델 결과를 평가할 지표다.

게임은 Steam App ID로 연결한다. A와 C의 사용자 ID는 직접 연결하지 않으며 실제 동일인의 중복 여부는 확인할 수 없다. 팀원의 EDA에서는 B와 C 명칭이 반대이므로, 협의할 때는 데이터 이름과 파일명을 함께 적는다.

## 입력 파일과 실행 범위

| 입력 | Colab에서 표시된 크기 | 이번 분석에서 읽힌 내용 |
|---|---:|---|
| A `games.csv` | 4.9 MB | 50,872행 |
| A `games_metadata.json` | 17.5 MB | 50,872개 객체 |
| A `recommendations.csv` | 824.2 MB | 16,819,477행 |
| B `games_march2025_cleaned.csv` | 468.6 MB | 89,618행 |
| C `australian_user_reviews.json` | 26.3 MB | 사용자 프로필 25,799행, 내부 리뷰 59,305건 |

B와 C의 표시 크기는 이 작업 공간의 파일 크기와 소수점 한 자리 MB 기준으로 같다. **크기가 같다는 사실만으로 파일 내용이 동일하다고 검증된 것은 아니다.** 원본의 버전·다운로드 일시·파일 해시를 별도로 기록하면 재현성을 높일 수 있다.

## A와 B 게임 정보

A 게임 목록은 **50,872개**, B는 **89,618개** 행이다. 두 데이터 모두 이번 ID 검사에서 결측·형식 오류·중복 게임 ID가 발견되지 않았다. A 메타데이터 역시 50,872개 객체에서 ID 결측·형식 오류·중복이 발견되지 않았다.

A의 `linux` 값을 기준으로 Linux 지원 게임은 **9,041개**다. 이 중 **6,440개**는 B에서도 해당 게임의 운영체제 값을 확인할 수 있었다. 그 6,440개 중 **58개**는 B에서 Linux 미지원으로 표시됐다. 기록 시점이나 출처 차이 등 원인을 확인하고, 최종 실험에서 Linux 지원의 기준을 팀이 정해야 한다. 이 EDA는 A를 기준으로 삼았다.

### 콘텐츠 보유 현황

아래 표의 콘텐츠는 설명·장르·태그 등 **확인한 필드 중 하나 이상이 비어 있지 않은 경우**를 뜻한다. B의 미연결 게임도 B 콘텐츠 없음에 포함된다. 텍스트가 있다는 사실은 내용의 품질이나 모델 적합성을 보장하지 않는다.

| A 콘텐츠 | B 콘텐츠 | A Linux 게임 수 | 해석 |
|---|---|---:|---|
| 없음 | 없음 | 56 | 양쪽에서 활용할 콘텐츠를 찾지 못함 |
| 없음 | 있음 | 126 | B를 통해 콘텐츠를 추가할 가능성이 있음 |
| 있음 | 없음 | 2,545 | 확인한 콘텐츠가 A에만 있음 |
| 있음 | 있음 | 6,314 | 양쪽에 콘텐츠가 있음 |

A 콘텐츠가 없는 게임 182개 중 126개는 B 콘텐츠가 있어, **B가 빠진 콘텐츠를 보강할 근거가 확인됐다.** 양쪽 콘텐츠가 모두 없는 56개를 최종 후보에서 제외할지 또는 다른 정보를 사용할지는 이후 결정한다. A와 B의 문장을 함께 쓸 때 중복 설명과 실제 텍스트 품질도 검토해야 한다.

## A 리뷰 분석: Colab에서 읽힌 범위

| 항목 | 결과 |
|---|---:|
| 읽힌 리뷰 행 | 16,819,477 |
| 서로 다른 사용자 ID | 8,226,623 |
| 서로 다른 게임 ID | 2,827 |
| 긍정 리뷰 | 14,447,691 |
| 부정 리뷰 | 2,371,786 |
| 긍정 비율 | 85.90% |
| 사용자–게임 중복 조합 / 추가 행 | 5 / 5 |
| 읽힌 리뷰의 날짜 범위 | 2010-10-15 ~ 2022-12-31 |

읽힌 행에서 사용자 ID·게임 ID·날짜·플레이 시간의 결측이나 음수 플레이 시간은 발견되지 않았다. 추천 여부를 판별하지 못한 행도 없었다. 다만 오류로 건너뛴 행이 있는지 알 수 없으므로 이 결과를 원본 전체의 품질로 확정할 수 없다.

### 사용자 이력

긍정 리뷰가 있는 사용자 **7,483,112명**의 긍정 리뷰 행 수 중앙값은 **1건**, 90백분위수는 **4건**이다. 긍정 리뷰가 1건인 사용자는 **4,930,618명**으로 약 **65.9%**, 3건 이상인 사용자는 **1,292,799명**으로 약 **17.3%**다. 이 수치는 중복 제거 전의 행 수이며 서로 다른 게임 수와 항상 같지는 않다.

관측 범위에서는 이력이 짧은 사용자가 많다. 다만 리뷰 행의 일부만 선택한 파일이라면, 원본에서 여러 리뷰를 작성한 사용자도 이번에는 1건만 나타날 수 있다. **이 수치만으로 전체 사용자의 이력이 부족하다고 결론 내리면 안 된다.** 사용자별 분석에는 전체 리뷰 집계 또는 사용자 단위로 추출한 대표 표본이 더 적합하다.

### 연도와 인기 게임

읽힌 리뷰에서는 2020~2022년 리뷰가 상대적으로 많다. 긍정 리뷰 상위에는 Rust, Counter-Strike: Global Offensive, Wallpaper Engine 등이 있다. 이는 **분석된 행의 결과이며 Linux 게임만의 순위가 아니고**, 전체 원본의 연도별 비율이나 인기 순위를 확정하지 않는다.

추천 시스템에 특정 인기 게임이 과도하게 노출될 가능성은 후속 실험에서 검토할 만하다. 현재 상위 목록만으로 전체 데이터의 인기 집중도나 실제 추천 편향을 정량화할 수는 없다.

## C 외부 평가 데이터

| 항목 | 결과 |
|---|---:|
| 사용자 프로필 행 / 서로 다른 사용자 ID | 25,799 / 25,458 |
| 리뷰 | 59,305 |
| 긍정 / 부정 리뷰 | 52,473 / 6,832 |
| 연도를 확인할 수 없는 리뷰 | 10,119 (약 17.1%) |
| 사용자–게임 추가 중복 행 | 874 |

연도가 없는 리뷰는 2015년 이전인지 판정할 수 없다. 기획안의 날짜 분리 예시를 적용하려면 이런 리뷰를 어떻게 다룰지 정해야 하며, 연도를 임의로 추측하면 안 된다. 중복 리뷰도 한 건을 선택하는 기준을 마련해야 한다.

### A의 Linux 게임과 겹치는 외부 이력

다음은 **C의 긍정 리뷰 중 작성 날짜가 확인되고 2015-12-31 이전인 행**을 A `games.csv`의 Linux 게임과 연결한 탐색 결과다. 이 계산은 A 리뷰 파일이 아니라 A 게임 목록을 사용하므로, A 리뷰의 분석 범위와는 별개다.

| 항목 | 결과 |
|---|---:|
| 날짜 조건을 만족하는 C 긍정 리뷰 행 | 44,182 |
| 그중 A Linux 게임과 겹치는 리뷰 행 | 24,693 |
| 겹치는 서로 다른 게임 | 761 |
| 공통 게임이 1개 이상인 사용자 | 15,822 |
| 공통 게임이 2개 이상인 사용자 | 4,992 |
| 공통 게임이 3개 이상인 사용자 | 2,039 |

사용자 수는 누적 조건이므로 3개 이상 사용자는 2개 이상과 1개 이상에도 포함된다. **2,039명은 확정된 평가 사용자 수가 아니다.** A 학습에 실제로 남길 게임, C의 중복 해결, 취향 입력과 정답 분할을 적용하면 달라질 수 있다.

## 이 데이터로 프로젝트를 진행할 수 있을까?

현재 결과는 **프로젝트를 진행할 가능성을 보여 준다.** A에는 협업 필터링에 활용할 사용자–게임 리뷰가 있고, A와 B에는 콘텐츠 기반 추천에 활용할 텍스트가 있으며, C에도 A의 Linux 게임과 겹치는 긍정 리뷰가 있다. B가 A의 빈 콘텐츠를 보강할 수 있는 사례도 확인됐다.

다만 **전체 데이터의 적합성과 추천 성능이 검증된 것은 아니다.** 다음 사항을 확인한 뒤 최종 데이터 구성과 평가 방식을 정한다.

1. A 리뷰 파일을 Colab에서 어떤 방식으로 준비했는지 확인한다. 전체 파일을 쓰거나, 목적에 맞는 표본 추출 방식을 기록한다.
2. CSV 읽기에서 오류 행을 조용히 건너뛰지 않도록 수정하고, 누락·오류 행을 확인한다.
3. A와 B의 Linux 지원 불일치 및 콘텐츠 누락·중복을 검토하고 기준을 정한다.
4. A에서 최소 사용자·게임 이력 기준과 플레이 시간·부정 리뷰 활용 여부를 정한다. 기준에 따른 데이터 감소를 확인한다.
5. C의 날짜 없는 리뷰와 중복 처리, 입력·정답 분할, 모델 간 공통 후보 게임을 정한다. C 정답은 학습이나 설정 조정에 사용하지 않는다.
6. 날짜 분리는 A·C에 같은 사람이나 편집된 리뷰가 섞였는지 보증하지 않는다. C가 Linux 사용자라는 보장도 없고, 현재 메타데이터가 과거의 Linux 지원 상태를 재현한다고 볼 수 없다. 따라서 평가는 **외부 사용자 이력 복원**으로 설명한다.
7. 각 데이터 원본의 라이선스와 재배포 조건을 확인한다.

## EDA 재실행

Colab에서 EDA 노트북을 열고 Google Drive에 연결한 뒤 데이터 경로를 확인해 셀을 순서대로 실행한다. 코드가 기대하는 기본 경로는 다음과 같다.

```text
MyDrive/steam_preprocessing/data/
  A/games.csv
  A/games_metadata.json
  A/recommendations.csv
  B/games_march2025_cleaned.csv
  C/australian_user_reviews.json
```

`FULL_DATA = False`는 Colab에 있는 A 리뷰 파일의 앞부분 100만 행만 읽는다. 앞부분은 무작위 표본이 아니다. `True`는 Colab에 있는 A 파일을 읽는 설정이지만 파일의 완전성은 별도로 확인해야 한다. 현재 노트북의 `ignore_errors=true`는 결과 누락을 숨길 수 있으므로 위에서 설명한 검토 후 사용한다.

원본: [A — Game Recommendations on Steam](https://www.kaggle.com/datasets/antonkozyriev/game-recommendations-on-steam), [B — Steam Games Dataset](https://www.kaggle.com/datasets/artermiloff/steam-games-dataset), [C — Steam Video Game and Bundle Data](https://www.kaggle.com/datasets/pypiahmad/steam-video-game-and-bundle-data).
