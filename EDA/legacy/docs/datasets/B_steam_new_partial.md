# B · steam_reviews.json/steam_new.json — 일부 헤더만 검사한 대용량 파일

## 1. 상태: 학습·평가 **미사용**
- Kaggle 데이터셋 B의 파일 목록에는 `steam_reviews.json/steam_new.json` 경로로 표시된 약 **4.27 GB** 파일이 존재한다.
- 2026-11-03 초기 분석에서 **앞 64 MiB만** 받아 스키마를 점검했다. 그 흔적이 `data/raw/manifest.json`의 `partial_head_bytes: 67108864`와 `.head` 경로다.
- **완전한 파일 다운로드/전처리/사용은 수행하지 않았다.** 2026-11-06 재현 과정에서는 이 부분 파일을 원본 9개 파일 검증 대상에서 제외했으며, 현재 Git 저장소에도 부분 데이터는 없다.

## 2. 부분 샘플에서만 확인된 사실
- 초기 EDA 요약: 일부 샘플 약 39만 행에서 `recommend` 필드가 관찰되지 않았다.
- `user_id` 존재율은 대략 40% 수준으로 보고되었다(부분 샘플 기준).
- 따라서 **긍정/부정 추천 정답** 및 **일관된 사용자 단위 프로필**을 제공하는지 확인되지 않았다.
- 리뷰에 관한 다른 키, 실제 전기간 사용자 식별자 존재율, 수집 시점, 중복 분포는 **전체 파일 미검증** 상태다. 위 부분 샘플 결과를 전체 4.27 GB 특성으로 일반화하지 않는다.

## 3. 이번 프로젝트에서의 판단
- 사용자별 추천 정답은 **B/`australian_user_reviews.json`**의 `recommend`로 구성.
- 새 베이스라인을 만드는 단계에서 `steam_new.json`을 불필요하게 다운로드하거나 긍정 레이블 데이터로 잘못 사용하지 않기.
- 추후 다른 실험에서 필요하다면 **사용자 식별자, App ID, 명시적 추천 여부, 날짜, 중복, 라이선스**부터 별도 파일 사전으로 검증한다.
