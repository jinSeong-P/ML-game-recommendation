# B · australian_user_reviews.json — 외부 테스트 정답용 리뷰

## 1. 역할과 형식
- **원본**: B/`australian_user_reviews.json` (약 26.3 MB).
- **한 줄**: 사용자 1명의 리뷰 묶음. 내부 `reviews` 리스트의 각 요소가 **리뷰 1건**이다.
- **형식**: 한 줄마다 Python 딕셔너리 리터럴이므로 `ast.literal_eval` 사용.
- **핵심 용도**: B 외부 평가에서 사용자별 **긍정 리뷰를 정답**으로 사용. A의 학습셋에 사용자 ID를 연결하지 않는다.

## 2. 원본의 키와 전처리 후 구조
| 원본 위치 | 키 | 의미 |
|---|---|---|
| 사용자 | `user_id` | B 데이터셋 내부 사용자 식별자 |
| 사용자 | `reviews` | 리뷰 배열 |
| 리뷰 | `item_id` | 문자열 Steam 게임 ID |
| 리뷰 | `recommend` | 사용자가 긍정 추천했는지(bool) |
| 리뷰 | `posted` | 작성 시점 표현(예: `Posted November 5, 2011.` / `Posted March 3.`) |
| 리뷰 | `last_edited` | 마지막 수정 표기(텍스트) |
| 리뷰 | `helpful` | 리뷰 반응 설명 문자열 |
| 리뷰 | `funny` | 리뷰 반응 설명 문자열 |
| 리뷰 | `review` | 리뷰 본문 텍스트 |

전처리에서는 **리뷰 본문을 그대로 저장하지 않고 길이 `review_len`으로만 바꾼다**. 분석용 `B_reviews.parquet` 12열: `line_no, user_id, item_id_raw, recommend, posted, last_edited, helpful, funny, review_len, item_id, posted_has_year, posted_date`. `line_no`와 뒤 4개 가공 필드(`review_len`, `item_id`, `posted_has_year`, `posted_date`)는 원본 열이 아니다.

연도가 없는 `posted` 값에 **임의의 연도를 채워 넣지 않는다**. 2026-11-06 EDA의 외부 평가 정답 24,704쌍 중 날짜가 없는 것은 3,360쌍(13.60%)이다.

## 4. 외부 평가셋 만들 때 주의
- 기본 평가 프로토콜: 보유 게임 입력 ≥5개, A와 매칭되는 공식 Linux 긍정 정답 ≥1개 → **15,294명 / 정답 24,704쌍 / 829게임**.
- 동일 사용자의 리뷰 게임은 **부정 리뷰 포함 전부** `australian_users_items.json`의 입력 목록에서 빼야 한다. 그렇지 않으면 답을 미리 알려 주는 누출이 생긴다.
- B의 인기 게임 쏠림: 정답의 **64.0%**가 A Linux 인기 상위 50개에 포함. 인기순 기준선도 Recall@10 **0.5386**에 도달하므로 모델 차이를 전체 Recall만으로 판단하기 어렵다.
- 평가용 정답 게임 중 **6개는 B의 보유 목록에 등장하지 않으며**, 전체 정답의 **17.7%**를 차지한다. 원인은 미확정. 이를 전처리 오류라 단정하지 않는다.
- 보유 데이터에는 소유·획득 시각이 없고 A 학습 리뷰는 2022년까지 존재한다. B는 **시점 정렬된 온라인 미래 예측 벤치마크가 아니다**.

## 5. 베이스라인 전처리 제안 (미구현)
1. `recommend`를 올바른 bool로 파싱, `item_id`를 숫자로 변환하고 변환 실패 로깅.
2. `(user_id,item_id)` 단위 중복 제거 후 긍정 라벨만 정답으로 사용. 부정 리뷰는 입력 제거 대상으로 사용.
3. A 게임 ID/공식 Linux 지원 필터 적용 후 사용자별 정답 집합 구축.
4. 정답이 0개인 사용자를 평가 사용자 집합에서 제거하되 제외된 사용자·게임 규모를 함께 기록.
5. 정답과 입력의 교집합이 공집합인지 `assert` 수행. 사용자별 Recall@10/NDCG@10 평균 및 롱테일을 함께 계산.
6. B를 최종 테스트로 고정하고 하이퍼파라미터 선택에는 A 내부 검증 데이터만 사용.
